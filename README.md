# Q-Day Wallet

A quantum-safe smart wallet: spend authorization by **NIST ML-DSA-44 (FIPS 204)**, admitted
through **EIP-8141 frame transactions on the standard alt-mempool** (canonical mempool's
~100k verification budget rejects it), identity continuity on **ENSv2**, and a public
migration registry on **Arkiv** (+ Swarm passport).
