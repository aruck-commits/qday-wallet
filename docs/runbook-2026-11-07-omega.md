# PROMPT-Ω execution runbook

Standing rules: raw HTTP evidence only; never normalize rule strings; secrets are never printed; no `debug_*` calls; commit every 30–45 minutes; push every commit; update `AI_USAGE.md` and a `specs/prompts/` entry per major block; never vendor workshop sources. Scripts remain idempotent and re-runnable from state files; never redo mined transactions or resubmit known/admitted frames.

- [ ] Ω-0 · Setup: create this runbook, commit `docs: omega runbook`, and push.
- [ ] Ω-1 · G3 part 1: perform two-poll liveness and participant-balance preflight; run `yarn deploy:devnet --fresh`; deploy factory, verifier, and QDayWallet with 0.15 ETH creation value, 0.002 gwei legacy gas, and 6M gas; registerA and registerT; assert both registry entries; commit `feat: G3 deploy and precompute`.
- [ ] Ω-2 · Gateway exhibits: probe peers and wait in five-minute cycles for up to 20 minutes. If peers remain zero, record the verbatim hard-stop and continue to Ω-3, then re-probe once after Ω-3. If peers are available, in order: raw-capture the G1 unstaked leg; submit and poll the G1 staked leg; submit and poll the G3 PQ frame. Commit `feat: G1 staked and unstaked raw evidence`, then `feat: G3 PQ frame admitted and mined`.
- [ ] Ω-3 · G4 gate body: preflight relayer balance; read the ENSv2 authorization model from the pinned clone; implement and execute `scripts/ens_write.ts`; read back through UniversalResolverV2; commit `feat: G4 ens write via executePq`; implement and execute `scripts/ens_rotate.ts`; read back and verify ownership; commit `feat: G4 rotation preserves name`. If the write path fails twice, record the exact error and missing authorization piece and continue.
- [ ] Ω-4 · G5b Swarm passport: build the passport, upload through a public Swarm gateway, byte-compare read-back, patch Arkiv `swarmRef`, and fill `arkiv/swarm.md`. If the public gateway rejects for over 40 minutes, record the verbatim response and skip. Commit `feat: G5b swarm passport`.
- [ ] Ω-5 · Evidence and UI completion: regenerate `demoEvidence.json`; preserve honest unavailable fields unless mined artifacts exist; complete S2–S5 and the S1 evidence lanes per `specs/UI_SPEC.md`; run `bun run app:build` and preview smoke; commit each screen meaningfully.
- [ ] Ω-6 · G7 submission package: update README evidence table, honest limitations, attribution, `docs/DEMO_SCRIPT.md`, `docs/VIDEO.outline.md`, and `SUBMIT_CHECKLIST.md`; run Forge and app builds; commit `feat: G7 submission package` and push.
- [ ] Ω-7 · Wrap: verify `origin/main == local` and print only the required final JSON with block statuses, links, and exact missing-for-submission reasons.
